# ⏰ Python Alarm Clock

A simple alarm clock application built using Python and Pygame.  
The program allows the user to set an alarm time and plays an audio file when the specified time is reached.

## 🚀 Features

- Set an alarm time
- Continuously checks the current time
- Plays an alarm sound when the target time is reached
- Uses Pygame for audio playback
- Simple command-line interface

## 🛠️ Technologies Used

- Python 3.11
- Pygame 2.6.1
